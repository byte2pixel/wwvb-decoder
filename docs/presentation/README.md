# Presentation

Talk for the Dec 7–11, 2026 on-site, planned for Thursday, Dec 10.

## Outline

1. What WWVB is
2. History: how NIST's time stations came about
3. How it's used today
4. The signal: 60 kHz carrier, AM pulse widths, phase modulation
5. The time code frame
6. The project: hardware, firmware, host, UI
7. Live demo: from radio to decoded time
8. Parallels to HART
9. Lessons learned

`images/` holds figures and photos for the slides.

## The live demo

[`demo-runbook.md`](demo-runbook.md) is the checklist for item 7: what to bring, what to do in the room before the talk, the order of the demo with what the screen should show, the fallbacks, and what to do when something goes wrong. The dry runs are recorded at its end.
